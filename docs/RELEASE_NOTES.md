# Shihon 1.0.0 · 纸本 / 紙本

## 简体中文

Shihon 1.0.0 正式版，适用于 Android 8.0 及以上的 arm64-v8a 设备。

- SmartOS 4 水波纹翻页。
- 亮度、对比度、Gamma 和离线文字增强。
- 独立图像构建队列、批量操作与自动处理。
- 横页全图查看、自动放大、分区阅读与自定义裁切。
- 完整的中文、英文、日文界面和文档。

下载 `Shihon-v1.0.0-arm64-v8a-release.apk`，通过 `SHA256SUMS.txt` 校验。详细功能见 [中文 README](https://github.com/conezcc/Shihon/blob/v1.0.0/README.md)。

## English

Shihon 1.0.0 for Android 8.0+ on arm64-v8a devices.

- SmartOS 4 water-ripple page turns.
- Brightness, contrast, gamma and offline text enhancement.
- Independent preprocessing queue, batch operations and automatic processing.
- Full-page viewing, wide-page zoom, region navigation and custom cropping.
- Complete Chinese, English and Japanese UI and documentation.

Download `Shihon-v1.0.0-arm64-v8a-release.apk` and verify it with `SHA256SUMS.txt`. See the [English README](https://github.com/conezcc/Shihon/blob/v1.0.0/README.en.md).
